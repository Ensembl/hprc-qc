# HPRC Ensembl-CAT Annotation Comparison

This workflow compares Ensembl and CAT annotations for HPRC assemblies and
generates the intermediate summaries used by the Marker 2 supplementary figure
and supplementary tables.

The final paper outputs are generated by the notebooks in `notebooks/` from
completed workflow output directories. The notebooks intentionally require
explicit absolute paths for the full-feature run, matched-feature run and
handover output directory.

## Workflow Inputs

The workflow input CSV must contain:

```text
assembly_accession,sample_name
GCA_041900255.1,HG00408_pat
```

The full HPRC sample sheet used for the Marker 2 comparison is:

```text
sample_sheets/hprc_assemblies.csv
```

The workflow also requires an ENSG lookup table passed with `--ensg_lookup`.
This is used when comparing gene presence for annotations where the shared gene
identifier is not directly available as a common gene name.

## Full Feature Set Run

Use this form for the unfiltered comparison:

```bash
nextflow run /path/to/hprc-qc/nextflow/pipelines/ensembl_cat_comparison/main.nf \
  --outdir results_full \
  --input /path/to/hprc-qc/nextflow/pipelines/ensembl_cat_comparison/sample_sheets/hprc_assemblies.csv \
  -profile slurm,singularity \
  --ensg_lookup /path/to/ensg_lookup.tsv \
  -resume
```

## Matched Feature Set Run

For the matched-feature comparison used in the final figure, CAT annotations are
filtered to remove `unknown_likely_coding` features and readthrough genes before
running the same comparison workflow.

```bash
nextflow run /path/to/hprc-qc/nextflow/pipelines/ensembl_cat_comparison/main.nf \
  --outdir results_no_kinnex_readthrough \
  --input /path/to/hprc-qc/nextflow/pipelines/ensembl_cat_comparison/sample_sheets/hprc_assemblies.csv \
  -profile slurm,singularity \
  --ensg_lookup /path/to/ensg_lookup.tsv \
  --filter_cat_gff true \
  --filter_cat_filter_name no_kinnex_readthrough \
  --filter_cat_exclude_biotypes unknown_likely_coding \
  --filter_cat_exclude_gene_name_file /path/to/readthrough_gene_names.gencode_v47.txt \
  -resume
```

## Readthrough Gene Name List

Create the readthrough gene-name list from the GENCODE v47 GFF3 source
annotation. The command below extracts unique gene names from features tagged
with `readthrough_transcript`.

```bash
GENCODE_V47_GFF3=/path/to/gencode.v47.annotation.gff3.gz

python3 - "$GENCODE_V47_GFF3" > readthrough_gene_names.gencode_v47.txt <<'PY'
import gzip
import sys
import urllib.parse

gff3 = sys.argv[1]
open_text = gzip.open if gff3.endswith(".gz") else open
gene_names = set()

with open_text(gff3, "rt") as handle:
    for line in handle:
        if line.startswith("#"):
            continue
        fields = line.rstrip("\n").split("\t")
        if len(fields) < 9:
            continue

        attrs = {}
        for item in fields[8].split(";"):
            if "=" not in item:
                continue
            key, value = item.split("=", 1)
            attrs[key] = urllib.parse.unquote(value)

        tags = {tag.strip() for tag in attrs.get("tag", "").split(",") if tag.strip()}
        if "readthrough_transcript" not in tags:
            continue

        gene_name = attrs.get("gene_name") or attrs.get("Name")
        if gene_name:
            gene_names.add(gene_name)

for gene_name in sorted(gene_names):
    print(gene_name)
PY
```

The resulting file is passed to the matched run with
`--filter_cat_exclude_gene_name_file`. The workflow audit files in
`filtered_cat_gff/` record how many CAT models were removed by this filter and by
the `unknown_likely_coding` biotype filter for each assembly.

FULL_FEATURE_RUN_OUTDIR = ''

## Draft Supplementary Methods Text

We compared Ensembl and CAT gene annotations for each HPRC haplotype assembly
using a Nextflow workflow. For each assembly, Ensembl and CAT GFF3 annotations
were retrieved, Ensembl sequence names were normalised using the corresponding
NCBI assembly report, and genes were paired by genomic overlap. Reciprocal best
hit gene pairs were used for transcript-structure, CDS and reference-divergence
analyses, while all overlapping pairs were retained separately for multi-mapping
summaries.

For transcript concordance, transcript exon structures were compared in both
directions within each reciprocal best hit gene pair. Transcripts were assigned
to ordered match classes including exact exon-coordinate match, shared intron
chain, partial overlap and no match. Counts were summarised by feature class for
the full annotation set and for a matched-feature CAT set.

The matched-feature CAT set was generated by excluding CAT models with gene or
transcript biotype `unknown_likely_coding`, which denotes models originating
from Kinnex-supported evidence, and by excluding CAT models whose gene names
matched a GENCODE v47 readthrough gene-name list. The readthrough list was
derived from GENCODE v47 GFF3 features tagged `readthrough_transcript`. Filtered
workflow runs retained per-assembly audit tables recording the number of removed
models and the predicate responsible for removal.

For divergence relative to the reference annotation, one representative
transcript was selected per reciprocal best hit gene pair and compared with the
corresponding GENCODE v47 reference transcript. Gene pairs were classified as
both matching the reference, both diverging from the reference in the same way,
Ensembl-specific divergence, CAT-specific divergence or insufficient data. The
supplementary figure reports these categories as within-biotype percentages.

For protein-coding reciprocal best hit pairs, CDS structures were compared with
the GENCODE v47 reference CDS annotation. CDS changes were grouped into exact
match, in-frame shorter, in-frame longer, frameshift shorter, frameshift longer
and coding lost. The main panel summarises the dominant agreement between the two
annotation methods, and the inset decomposes the non-exact CDS classes.

Supplementary tables were generated from the workflow outputs using the
companion notebook. The paper table of recurrent CDS-reference discordance is
filtered to genes observed in more than one assembly. Additional assembly-level
and gene-level tables are written for GitHub or data-deposit release rather than
included directly in the manuscript supplement.
